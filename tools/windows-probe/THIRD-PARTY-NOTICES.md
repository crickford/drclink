# Included Microsoft components

The portable build contains unmodified Microsoft .NET Runtime 8.0.32 (Windows x64) and the Microsoft Windows SDK for .NET 8 targeting pack 10.0.19041.56 runtime projection assemblies (Microsoft.Windows.SDK.NET.dll and WinRT.Runtime.dll).

.NET runtime licenses and notices are included in runtime/LICENSE.txt and runtime/ThirdPartyNotices.txt.

.NET runtime source: https://github.com/dotnet/runtime
.NET runtime download source: https://builds.dotnet.microsoft.com/dotnet/Runtime/8.0.32/dotnet-runtime-8.0.32-win-x64.zip
